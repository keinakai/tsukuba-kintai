# 筑波大学 出退勤 かんたん打刻アプリ

「出勤」「退勤」の大きなボタンを押すだけで、勤怠ポータル
（裁量労働制適用職員出退勤等管理システム / skinmu）に自動で打刻するアプリです。
**Mac・Windows どちらでも使えます。**

- **パスワードはアプリのファイルに保存しません。** アプリの「⚙ ログイン設定」で
  ID・パスワードを登録すると、OS標準の安全な保管庫（Macはキーチェーン、Windowsは
  資格情報マネージャー）に保存され、ログイン画面が出ても自動でログインします。
  登録しない場合は毎回手動ログインです。
- 打刻の控えは手元にも `打刻記録.csv` として自動保存されます。

---

## 使い方（3ステップ）

### 1. 初回セットアップ（最初の1回だけ）

**Mac の場合：** `setup.command` をダブルクリック。
（「開けません」と出る場合は右クリック →「開く」→「開く」）

**Windows の場合：** `setup.bat` をダブルクリック。
（「WindowsによってPCが保護されました」と出る場合は「詳細情報」→「実行」）

どちらも、Python と自動操作用ブラウザが入ります。数分かかります。

> Python が入っていないと言われたら、先に https://www.python.org/downloads/ から
> Python 3 をインストールしてください。
> **Windowsの場合、インストール画面の最初のチェックボックス
> 「Add python.exe to PATH」に必ずチェックを入れてください。**（これが無いと動きません）

### 2. アプリを起動
Mac：`出勤退勤アプリを起動.command` を、Windows：`出勤退勤アプリを起動.bat` を
ダブルクリック。「出勤」「退勤」ボタンの画面が開きます。

### 3. 打刻する
- **最初に一度**：アプリの「⚙ ログイン設定」ボタンから統一認証のID・パスワードを
  登録してください（OS標準の保管庫に保存されます）。
- あとは「出勤」「退勤」を押すだけ。ログイン画面が出ても自動でログインして打刻します。
- ログイン設定を登録しない場合は、ログイン画面が出たときに手動で入力してください。

---

## ボタンの文字が合わないとき

ポータル画面の出勤/退勤ボタンの表示が「出勤」「退勤」以外（例：「出勤打刻」など）の
場合は、`config.json` を開いて次の値を実際の表示に合わせて書き換えてください。

```json
"clock_in_button_text": "出勤",
"clock_out_button_text": "退勤",
"confirm_button_text": ""
```

- `confirm_button_text`：打刻後に「OK」「確定」などの確認ボタンが出る場合、その文字を入れます。
- 書き換えたら保存して、アプリを起動し直してください。

## よくある質問

**Q. 打刻時刻はいつになりますか？**
ボタンを押した時点でポータルの打刻ボタンをクリックします。実際の登録時刻はポータル側の
仕様に従います（画面はブラウザに表示されるので、その場で確認できます）。

**Q. うまくボタンが押せなかった**
ログ欄に「ボタンが見つかりませんでした」と出た場合は、`config.json` のボタン文字を
画面表示に合わせて直してください。ブラウザは開いたままになるので、その場で手動打刻も可能です。

**Q. 安全ですか？**
ID・パスワードはアプリのファイルには一切保存されません。「⚙ ログイン設定」で登録した
場合は、OS標準の暗号化保管庫（Macはキーチェーン、Windowsは資格情報マネージャー）に
本人のPC内でのみ保存されます。このフォルダを配布しても、ログイン情報が他人に渡ることは
ありません。

**Q. パスワードを変更した**
アプリの「⚙ ログイン設定」からもう一度登録し直してください（上書きされます）。

**Q. Windowsで「WindowsによってPCが保護されました」と出る**
配布元不明のファイルへの標準の警告です。「詳細情報」をクリックし、「実行」を押せば
起動できます。

## 保存される場所

**Mac：**
- ログイン状態： `~/Library/Application Support/TsukubaKintai/browser_profile`
- 打刻の控え： `~/Library/Application Support/TsukubaKintai/打刻記録.csv`
- 直近の打刻画面： `~/Library/Application Support/TsukubaKintai/最終打刻_出勤.png` など

**Windows：**
- ログイン状態： `%APPDATA%\TsukubaKintai\browser_profile`
- 打刻の控え： `%APPDATA%\TsukubaKintai\打刻記録.csv`
- 直近の打刻画面： `%APPDATA%\TsukubaKintai\最終打刻_出勤.png` など
